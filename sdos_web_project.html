SDOS Web Project

Associated with SDOS - Sachintha Dilshan Online School

Apr 2024 - Present
SDOS Platform - Landing View 1 of 5

Platform Overview

SDOS (Sachintha Dilshan Online School) is a versatile, secure e-learning platform engineered to provide high-quality education to Sri Lankan students from Grade 6 to G.C.E. Advanced Level.

Designed with modern web technologies, the platform provides seamless video lectures, downloadable tutorial resources, student attendance tracking, and intuitive dashboards for students and parents.

🛡️

Secure Authentication

Multi-tier role access ensuring student and administrative accounts are strictly isolated.

📚

Structured Curriculum

Courses organized comprehensively from Grade 6 up to Advanced Level Bio & Math streams.

📱

Full Mobile Responsiveness

Tailored UI allowing students to learn smoothly on smartphones, tablets, or laptops.

⚡

High Performance & Uptime

Optimized asset loading and caching ensuring low latency across all mobile networks in Sri Lanka.

Technology Stack & Competencies

Python Django Framework HTML5 & CSS3 JavaScript Tailwind CSS Secure Authentication Cloud Hosting Git & GitHub
